# INVERSE-OF-A-MATRIX
## Aim:
To write a python program to find the inverse of a matrix
## Equipment’s required:
1. 	Hardware – PCs
2. 	Anaconda – Python 3.7 Installation / Moodle-Code Runner
## Algorithm:
### Step1 : Import the NumPy library.
### Step 2: Input the matrix and store the elements.
### Step 3: Use the function numpy.linalg.inv() to calculate the inverse of the matrix.
### Step 4: Display the inverse matrix and end the program.

## Program:

```
import numpy as np

A = np.array([[2, 1, 1],
              [1, 1, 1],
              [1, -1, 2]])

inverse = np.linalg.inv(A)

print("Inverse of the matrix is:")
print(inverse)
```
